## Project Documentation

This project is a responsive personal portfolio website built using semantic HTML and CSS. Tailwind utility classes are compiled into a local stylesheet, so the pages run without JavaScript.

### Features

- **Personal Profile:** Includes a page title, main heading, About Me paragraphs, a Skills list, and a Contact section with an email link.
- **Responsive Card Layout:** Uses Tailwind CSS utilities and custom CSS for colors, spacing, borders, typography, cards, and mobile navigation.
- **Portfolio Navigation:** Links to the existing Experience and Projects pages remain available from the profile page.
- **SEO Friendly:** Semantic HTML and optimized resources for better search engine visibility.
- **Customizable:** Easily modify content and styles to suit your personal or business portfolio needs.

### Getting Started

1. **Clone or Download:**  
   Download or clone the project folder.

2. **Open in Browser:**  
   Double-click `index.html`, or serve the folder locally with `python -m http.server`.

3. **Customize:**  
    Edit the HTML file to update your personal information, projects, and styles.
